# Wok & Ember — Dapur Rush

**Wok & Ember — Dapur Rush** is an original, fast-paced cooking simulation game built for the make.fun bounty. Manage your kitchen during intense 150-second shifts, prepare ingredients across multiple stations (Grill, Chopping Board, Fryer), assemble plates according to customer orders, and maintain your combo and patience meter to achieve the highest score!

## Features
- **4 Delicious Recipes:** Burger Api, Burger Keju, Salad Segar, and Nasi Telur Ember.
- **Interactive Cooking Stations:** Grill patties, chop fresh vegetables, and fry eggs to perfection before they burn.
- **Combo & Patience System:** Serve orders quickly to build up combo multipliers and earn bonuses.
- **Polished Web Experience:** Built with vanilla HTML5 Canvas and modular ES6 JavaScript with retro arcade aesthetics and sound effects.

## Run It

To play the game locally:
1. Navigate to the game directory or serve it with any static web server:
   ```bash
   cd game
   python3 -m http.server 8000
   ```
2. Open `http://localhost:8000` in your web browser.
